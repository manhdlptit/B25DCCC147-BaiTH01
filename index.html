Giới thiệu về bản thân mình

Mình tên là Lê Đức Mạnh, đến từ Phú Thọ. Hiện nay đang là sinh viên khoá D25 của Học viện Công nghệ Bưu chính Viễn thông, ngành Cử nhân Công nghệ Thông tin. Sở thích của mình là chơi Rubik.

Danh sách kỹ năng lập trình

  • Sử dụng cơ bản GitHub
  • Hiểu cơ bản về HTML, CSS, JavaScript
  • Sử dụng HQTCSDL SQLite để truy vấn dữ liệu
  • Phát triển backend với Flask-Python
  • Tạo component cơ bản với Vite React-JS

Một vài dự án nhỏ mình đã làm

  • Máy tính cộng trừ nhân chia cơ bản

    • Các phép tính cộng trừ nhân chia cơ bản
    • Xử lý một vài lỗi logic nhỏ khi tính toán

  • Trang đặt vé xem phim rạp chiếu phim cơ bản

    • Truy xuất danh sách phim hiện có
    • Đặt vé xem phim

  • Backend authentication cơ bản

    • Đăng ký và đăng nhập hệ thống
    • Gọi API để xử lý dữ liệu
    • Dùng token để tạo mật khẩu tạm thời
    • Các luồng JWT: Phát, thu hồi, yêu cầu JWT
    • UnitTest để kiểm tra logic code
